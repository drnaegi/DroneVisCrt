# 两张无人机照片如何支撑新视角合成

## 技术路线与主要结果

用两幅已知机位的照片合成第三个机位。冻结 RAFT 提供源间匹配，冻结 MoGe-2 提供单目形状，双目观测校准尺度。自行实现的渲染器同时产生两幅目标图，一幅按表面可见性融合两个源，另一幅逆投影到一张源照片取细节。两者按频带合成，可选用从其他地区学习到的取色权重。合成输入仅为源图及相机参数。图文或跨视角关系标注属于下游问题。

在四个实拍地区的六条航线上，按地区等权。对共享的 59 个可插值目标，以地面预对齐 RIFE 为参照，固定频带版的差为 +0.057 dB PSNR、+0.0017 SSIM、−0.0174 LPIPS；按地区交叉验证的学习版为 +0.174 dB、+0.0091、−0.0044。四地共有 62 个目标，其中 3 个超出严格插值条件。学习权重中额外引入相机特征，相对仅用同样两幅渲染的图像特征，仅提高 0.0026 dB。方法独立实现和端到端指标已有证据，新的几何机制能否独立贡献足够大的收益，仍是 ICML 投稿判断的主要缺口。[全部机器结果](method_means.csv) · [同目标消融](paired_comparisons.json)

## 研究问题

给定两幅同一地点的航拍照片、相机内外参和一个目标机位，合成该机位可能拍到的 RGB 图。单目深度模型能辨认屋顶、树冠等高出地面的形状，但在新航线上的尺度和起伏程度可能有偏差。两图相互可见的区域能通过三角化提供独立于单目模型的几何观测，单幅可见区域则缺少这种约束。本文考察能否先在重叠区判断单目形状的可信程度，再将经过校验的深度用于另一个机位。输入无需场景描述。适用相机在地面上方、画面各角朝向地面。对无位姿单图和带地平线的镜头仍需另外的建模与评价。

## 已有技术和待验证的贡献

| 工作 | 已经解决的问题 | 本研究的处理 |
|---|---|---|
| View Morphing、Stereo Magnification | 双视图变形和以深度平面表示遮挡已有长期研究 | 把已知地面投影、双向光流插值、双目深度投影列为对照。[View Morphing](https://www.cs.cmu.edu/~seitz/vmorph/vmorph.html) · [Stereo Magnification](https://arxiv.org/abs/1805.09817) |
| RAFT、Softmax Splatting | 稠密图像对应与利用光流合成中间帧 | 使用冻结的 RAFT 估计源间双向对应。本实现通过实际目标相机投影，并用迭代逆变形选取源像素。[RAFT](https://arxiv.org/abs/2003.12039) · [Softmax Splatting](https://arxiv.org/abs/2003.05534) |
| MoGe-2、DepthSplat | 单张图恢复稠密三维形状，以及将单目先验与多视匹配联合用于新视角合成 | MoGe-2 仅预测深度。用单一全局尺度对齐 MoGe-2 是最接近的简单对照。DepthSplat 是比较完整学习式融合的外部基线。[MoGe-2](https://arxiv.org/abs/2507.02546) · [DepthSplat](https://arxiv.org/abs/2410.13862) |
| IBRNet、pixelSplat、MVSplat、ViewCrafter | 由源观测投影或学习场景表示以合成新视角 | MVSplat 使用 ACID 航拍检查点。另保留此前同输入 ViewCrafter 运行。候选方法自行计算三维坐标、目标投影和取色。[IBRNet](https://arxiv.org/abs/2102.13090) · [pixelSplat](https://arxiv.org/abs/2312.12337) · [MVSplat](https://arxiv.org/abs/2403.14627) · [ViewCrafter](https://arxiv.org/abs/2409.02048) |

**待验证的贡献**是在只有两张源图、没有目标监督时，判断哪些场景值得将单目起伏外推到非重叠区。融合深度、双向一致性、三角化以及源图取色均有先例。能否在真实新航线上超越“相同两图、相同模型、直接按三角化中位数校正单目尺度”，决定这一设计能否单独支撑方法论文。

## 合成算法

1. 使用源图之间的局部特征校准航拍遥测中的水平位移。已知合成场景直接使用发布的相机。所有变体与外部方法共用同一组相机。
2. RAFT 估计两个方向的稠密对应。对同一像素沿两条视线三角化，用正深度范围、画内判定和双向光流误差约束结果。用于估计单目校正参数的点另需满足前后向置信度、投影误差和视差阈值。
3. 以每条射线与统一地平面交点的轴向深度为基准。比较三个可选预测，即原地平面、全局高度比例修正，以及在对数空间用单目相对地面的起伏预测双目起伏。第三个模型稳健拟合斜率与截距。每 32 像素划空间棋盘，使用一半格点拟合，另一半比较截断对数深度误差。样本不足时保留地平面。复杂模型需要超过 0.005 的误差改进。相邻网格存在空间相关性，该验证仅用于源内选模。
4. 对于可靠对应，优先采用三角化深度。其它位置按双向一致性连续过渡到选出的深度先验。在三维重投影之外，按目标沿源间基线的有符号进度传递源间剩余二维误差，并限制外推幅度。目标偏离基线时，该标量只近似残差的真实运动。
5. 在目标栅格中逆查源坐标，通过往返误差、画内余量和机位距离选择供色源。无覆盖时沿用平面渲染的边界延拓。输出 RGB 和来源编号。这一逆采样分支在深度不连续处可能选错表面，后文的网格分支另做深度排序。相机投影覆盖也不能保证某物体实际可见。[核心实现](../../relation_nvs/stereo_transport.py) · [普通推理入口](../../tools/render_aerial_mosaic.py)

## 配对实验

目标 RGB 在生成阶段只作为文件名登记，评分阶段才解码。航拍下载阶段还从原始 JPEG 读取相机信息和文件哈希。FloodNet 使用既有选点规则。MatrixCity 使用官方融合子集中全部 12 张航拍测试图，按机位距离与光轴差从官方训练图选两源，在 512×288 评分。各实拍航线逐图等权，FloodNet 每地两图，因此地点等权与逐图等权等价。同一条航线的相邻帧具有相关性。全幅 PSNR、Gaussian SSIM 和 LPIPS-Alex 均在同一目标上计算，镜像填补区域也计分。另有每幅固定平面可覆盖区和补集的 PSNR。全幅指标与开题报告第 41 页要求的静态掩膜指标有不同含义。[MatrixCity 版本](../../datasets/matrixcity_fusion_20261116/README.md) · [既有 FloodNet 对照](../aerial_mosaic_validation/研究一_双源校准与图文扩增.md)

MVSplat 使用作者 ACID 架构和权重，使用项目指定的 CUDA 光栅化器。按原检查点的 256×256 和各组原评测输入尺寸都推理，均在相同目标尺寸直接渲染。将平均源高度设为 10 个模型单位，所有相机共同应用相似变换，近远界取官方 1 和 100。这是航测数据到 ACID 坐标的适配。除原生黑背景外，另对最大输入尺寸运行一次同地平面底图的透明度合成，避免把未覆盖区的黑边当作三维机制收益。DepthSplat 使用作者 DL3DV Base 256×448 权重及 0.5 至 200 近远界。两者与候选方法共用源照片、目标相机和评分代码。[MVSplat 上游](https://github.com/donydchen/mvsplat) · [DepthSplat 上游](https://github.com/cvg/depthsplat) · [MVSplat 适配](../../tools/benchmark_survey_mvsplat.py) · [DepthSplat 适配](../../tools/benchmark_survey_depthsplat.py)

## 表面可见性与图像细节

在同一组深度上比较两套取色方式。第一套对每张源图以 2 像素步长建三角网格，剔除角点深度比例超过 1.10 的三角形，把两张网格投到目标机位，用深度缓冲保留近表面。目标深度相差在 5% 以内的可见源可以按画内余量和相机距离加权。第二套按前述逆投影和往返误差选一个源取色，保留单张照片中的边缘。对第一幅渲染取高斯低通，对第二幅取同尺度高通后相加，标准差固定 1.5 个评测像素。工作区同时实现了根据局部位移误差衰减高频的版本。此频带分解借用了经典多分辨率融合原理。候选贡献是从两种几何渲染的不同取样误差出发分配颜色和细节，其独立效果由保留几何、仅换取色方式的消融测量。[多分辨率图像融合](https://doi.org/10.1145/245.247) · [表面渲染与频带组合](../../relation_nvs/survey_visibility.py) · [普通输入的双目标输出](example_surface_detail/manifest.json)

对比帧插值时，使用作者发布的 RIFE 4.26，分别在原图和两张已通过地面单应投影到目标栅格的源图上运行，以目标沿源间连线的有符号位置作为插值时刻。预对齐版在两源均覆盖区调用插值，其余沿用同一平面底图。此控制对近乎共线的真实航拍目标尤其重要。FloodNet 的外推组超出帧插值定义域，故单列。即使单应预对齐之后，超出地平面的结构仍有视差。[RIFE 论文](https://arxiv.org/abs/2011.06294) · [作者权重](https://huggingface.co/hzwer/RIFE) · [适配实现](../../tools/benchmark_survey_interpolation.py)

在这个有明确前景轮廓的物体上，深度校验相对中位数尺度提高 2.15 dB 前景 PSNR。两个渲染直接平均却有更高的前景 SSIM 和更低的全幅 LPIPS。迁移检验的独立场景数为一。

### 源机位偏离连线的控制实验

在 MatrixCity 的 12 个官方航空测试目标中，有 3 个满足两对源相机朝向、基线长度与方向、插值比例同时匹配的条件。固定同一个真实渲染目标，将两个源机位整体横移约 50 至 69 米。三维三角化加端点残差相对相同 RAFT 对应的二维地面光流，在共线条件下平均提高 0.003 dB，在偏轴条件下提高 0.023 dB。偏轴条件的增益主要来自一个目标。固定双路方法相对地面预对齐 RIFE 的 PSNR 差从 −0.177 dB 变为 +0.234 dB，偏轴组三个目标的平均 LPIPS 仍高约 0.003。平面投影覆盖率随源机位变化，这个小样本不能独立确认遮挡或深度是增益原因。三者复用原有测试目标，不计为新增城市或六个独立地点。[匹配约定](protocol_matrix_pose.md) · [相机筛选记录](matrix_pose_eligibility.json) · [共线组](matrix_collinear/scores.json) · [偏轴组](matrix_transverse/scores.json)

### 如何复现实拍比较

在当前工作区的仓库根目录执行以下命令。首条是正常推理入口，输入文件只需源照片与三组或更多相机参数。后两条以 Sand Key 为例，用固定 Git 版本和图像哈希恢复测绘数据，再生成所有对照、评分和地区汇总。输出目录可取一个尚未使用的路径。

```bash
export PYTHONPATH=. OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=2
survey_py=/autodl-tmp/DroneVisCrt/envs/viewcrafter/bin/python
"$survey_py" -m tools.render_aerial_mosaic outputs/aerial_mosaic_validation/example_input.json /tmp/nvs_two_views --method surface_detail
"$survey_py" tools/acquire_stereo_survey.py --survey sand_key
"$survey_py" -m tools.run_survey_benchmark sand_key
```

普通推理的校验深度版与中位数版均在 6374、6375 两个目标上与对应批量实验输出的 PNG 哈希一致。端到端评测入口在独立进程载入各外部模型，兼容已有工作区检查点。MVSplat 为原仓库 01f9a28、ACID 权重 253785de，DepthSplat 为 2dad25a、DL3DV Base 权重 02c7b19d，DINOv2 为 7764ea0，RIFE 4.26 权重为 45c7f741。外部模型适配包含固定坐标尺度和输入尺寸，分数只对应这些公开参数下的运行。运行器支持显式指定两个上游仓库、DINOv2 和编译好的光栅化器 Python 包位置。[评测入口](../../tools/run_survey_benchmark.py) · [算法及回归测试](unit_tests.log)

### 深度误差投到目标机位是否有帮助

用可靠同名点估计中位数尺度下单目对数深度的残差，用实际针孔相机投影对对数深度的解析导数，将像素匹配误差换算成三角化的深度方差，再按精度合并两者。投到目标视角时，再用目标相机的导数把深度方差转换成位置方差，降低高不确定源提供细节的机会。这一估计同时依赖匹配噪声模型和局部线性近似。[方法与参考公式的实现](../../relation_nvs/stereo_transport.py) · [实验约定](protocol_precision.md)

在四个实拍地区等权汇总中，完整误差传播相对简单中位数双路法为 −0.012 dB / −0.0010 / +0.0022。保持其深度不变，只将位置方差用于细节选源的差为 −0.009 dB / −0.0010 / +0.0020。MatrixCity 对同样中位数基线则为 +0.064 dB / +0.0042 / −0.0024。跨实拍地区的结果支持把这一机制保留为消融。普通推理入口的 `surface_precision` 与批量实验在 6374、6375 两个目标的输出哈希相同。[示例输出](example_precision/manifest.json)

### 学习在哪些位置组合两幅渲染

对两个取色分支的输出，各用标准差 1.5 和 4 像素的低通构造三个频带。每个频带在表面混色与逆采样单源之间做凸组合。训练目标是该频带的平方重建误差。常数版本每带估计一个权重；图像版再看各分支的相对能量和两者的分歧；几何版另看相机覆盖余量、机位偏离源间连线的距离和沿线位置。训练只需要小型正规方程。留一地区时，同一地区的全部航线、全部源图和目标图都留出。每折训练和留出地点所涉及的原始照片哈希交集均为空。额外保留使用四个地区训练的部署系数，供其它地点运行。[训练协议](protocol_learned_bands.md) · [各折训练来源与系数](band_weights) · [单图推理算法](../../relation_nvs/survey_bands.py)

| 配置，四地等权 | PSNR ↑ | SSIM ↑ | LPIPS ↓ |
|---|---:|---:|---:|
| 固定频带，低频表面加高频单源 | 21.673 | 0.4918 | 0.2027 |
| 两幅渲染逐像素平均 | 21.687 | 0.4955 | 0.2095 |
| 分带常数，从其它地区学习 | 21.759 | 0.4980 | 0.2149 |
| 分带权重仅用两幅渲染的图像特征 | 21.784 | 0.4990 | 0.2153 |
| 分带权重加入几何特征 | 21.786 | 0.4990 | 0.2155 |

对地面预对齐 RIFE，学习几何取色在共享目标上的地区等权差为 +0.174 dB / +0.0091 / −0.0044。相对固定频带，学习版本提高 0.113 dB，SSIM 提高 0.0072，LPIPS 回升 0.0128。从相同渲染的图像特征版到增加几何特征版，PSNR 仅增加 0.0026 dB。两幅初始渲染本身已经使用了几何；这一消融只隔离额外向取色权重提供相机特征的效果。仅在比较学习版本时有完全相同的航拍监督预算。小规模地点交叉验证显示，带监督的取色可以优化像素指标，也暴露出与感知相似度的取舍。

普通推理使用 `--method surface_learned`。需要重训系数或重做留地评测时，在有六航线基础渲染的工作区执行以下命令。系数一旦写出，普通输入不需要测试地点的 RGB 真值或训练数据。6374、6375 的普通入口预测已逐一与批量分数所用 PNG 的哈希核对。[完整示例](example_learned/manifest.json)

```bash
"$survey_py" -m tools.benchmark_survey_learned_bands train
"$survey_py" -m tools.run_survey_benchmark --learned monterey cross park1 park3 noema sand_key
```

### 新取图的五处 FloodNet 地点

在下载目标 RGB 前，固定了五个新的洪灾拍摄地点及训练系数。每个三元组的相机距离先前缓存的 107 张 FloodNet 照片均至少 300 米，五个目标之间至少相距 500 米。全部五组完成合成与评分。同一洪灾项目中的分散地点可以检验方法换地点的表现，其数据来源仍是 FloodNet。[固定协议与机位](protocol_flood_holdout.md) · [33 种配置的配对结果](flood_holdout/scores.json)

| 方法 | PSNR ↑ | SSIM ↑ | LPIPS ↓ |
|---|---:|---:|---:|
| 地面预对齐 RIFE | 21.764 | 0.5141 | 0.1958 |
| DepthSplat＋平面底图 | 21.154 | 0.4748 | 0.2657 |

### 研究一与投稿判断

在两张带相机参数的航拍照片条件下，固定频带的分工和学习像素误差最小的取色权重分别取得了更好的感知距离与像素误差。推理流程无需调用完整的 ViewCrafter、RIFE、MVSplat 或 DepthSplat。深度校验机制在 MatrixCity 的三维结构上有收益，在真实航线上的独立优势仍未建立。多分辨率融合、深度缓冲、单目与双目联合均已有工作；Deep Blending 已经将两种完整度和几何准确性互补的重建交给学习式视图混合，学习式视图加权也有直接先例。投稿需要解释在何种相机运动、遮挡和误差条件下这两种取样方式各自更可靠，并把这种解释与相同输入、相同预训练部件的简单融合直接比较。当前完整实验限于带相机的双源 NVS。开题中无位姿单图生成、按任务缺口选视角、生成样本对真实检测的收益分别需要对应实验。图文与跨视角关系标注可读取可见区域和源证据，已有固定关系结果仍不足以主张渲染改进提升了图文正确率。

相关比较还包括 Hedman 等的 Deep Blending，其输入和场景重建预算与这里的两张照片不同。[Deep Blending 作者页面](https://repo-sam.inria.fr/fungraph/deep-blending/)

### 双目点图、已知相机射线与官方优化器的同渲染器对照

冻结 DUSt3R 双向点图，以已知相机的源射线估计真实尺度与形状。在新增四城的十二个高度与俯仰插值目标上，该方法比官方 300 步优化器高 0.195 dB，几何阶段中位耗时由 5.638 秒降到 0.150 秒。六条实拍航线四地等权对同一优化器为 +0.026 dB，LPIPS 略高。实验还覆盖精度一致的单目对照、七自由度相似变换、可见性真值以及表面预对齐。研究一的更新结果和适用条件见独立报告。[相机射线标定与双源新视角合成](研究一_相机射线标定与双源新视角合成.md)
