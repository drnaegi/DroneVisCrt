# 实际静态区域与双源可见性的事后诊断

已观察全图结果，新增此诊断以对应开题的静态有效区域指标。采用 SynDrone 官方类别中明确固定于场景的建筑、围栏、灯杆、道路标线、道路、人行道、植被、墙、交通标志、地面、桥、轨道、护栏、信号灯、静态物和地形（1,2,5,6,7,8,9,11,12,14,15,16,17,18,19,22），同时要求目标轴深有效。水面、未定义、other、天空、车辆与行人不计入静态掩码。先在原标签栅格形成二值图，再以 BOX 缩到评测分辨率，仅保留覆盖率 100% 的像素。计算区域 PSNR、完全落在区域内的 11×11 高斯窗 SSIM。LPIPS 沿用未经掩盖的全画幅，表中明确标注。用模拟器三张轴深缓冲将静态像素分成零、一、二个输入相机可见，前后深度吻合误差小于或等于源深度的 5%。分区由真值独立确定，所有方法使用同一掩码。分区用途为解释误差来源，不替代已发表的全图汇总。
