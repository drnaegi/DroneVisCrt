# 研究一 GitHub 保存清单

本清单面向双源已知相机的新视角合成，沿用本仓库已有 Git 历史。在仓库根目录可用下列命令预览候选文件。

```bash
git add --dry-run --pathspec-from-file=outputs/aerial_stereo_study/github_snapshot/files.txt
```

## 可恢复的内容

- 逐项文件名见 [files.txt](files.txt)。包括本地实现与脚本、主实验和消融、冻结协议、划分、逐机位结果、运行时间、回归测试及少量样例图。主结论见[研究报告](../研究一_相机射线标定与双源新视角合成.md)。
- [数据清单副本](data_manifests.json)保留被 Git 忽略的数据目录中的航线清单和 SynDrone 原始归档成员记录。顶层键对应原路径。两批 Rubble 的照片名、相机参数、校准记录和散列另见研究目录中的 selection、cases、eligibility 文件。下载脚本支持恢复这两组数据及两批 SynDrone 高度实验。
- 如需直接给旧图加指标，另存原尺寸预测 PNG、评分所用的真实目标图、掩码与深度，并保持原目录结构。跨视角关系标签若需要引用同一像素来源，还要保留对应来源图和已有几何记录。各组 predictions.json 记载的路径可跨到 datasets 与更早的 outputs 目录。研究目录以外的四城 ViewCrafter 历史生成帧及原优化器的 prediction.npz 也属于复跑相应旧对照所需的外部产物。按需将这些文件备份到对象存储或数据仓库，另记地址、版本和散列。现有分数可以直接查阅。
- 主方法所用 DUSt3R 代码位于 code/viewcrafter-sparse/extern/dust3r。父仓库忽略这个检出目录。恢复时将 Drexubery/ViewCrafter 检出到 code/viewcrafter-sparse，固定提交 97cdb8634b28708cbd50912d57c52f23c5ffbf09。该目录的 DUSt3R 与 CroCo 受版本控制源码在本机与该提交一致。[代码版本](https://github.com/Drexubery/ViewCrafter/tree/97cdb8634b28708cbd50912d57c52f23c5ffbf09/extern/dust3r)
- 放置 DUSt3R 权重到 checkpoints/DUSt3R/model.safetensors。官方权重版本见[点图实验协议](../protocol_pointmaps.md)，SHA256 为 7c300a89534113436bde52732d3151212bcbd90f0aa3c8d1496f86d84bfe4b42。RAFT 使用 torchvision 的 Raft_Large_Weights.C_T_SKHT_V2。MapAnything 的权重和代码版本见[对照协议](../protocol_mapanything.md)。部分基线脚本引用本机 /autodl-tmp/DroneVisCrt 下的额外代码和依赖目录，迁移时需恢复或调整路径。
- 本机主实验环境为 Python 3.12.3、PyTorch 2.5.1+cu124、torchvision 0.20.1+cu124、CUDA 构建版本 12.4、NumPy 1.26.4、SciPy 1.16.2、OpenCV 4.11.0、Pillow 11.0.0、safetensors 0.8.0、scikit-image 0.25.2、LPIPS 0.1.4。以上是运行环境中核实的主要版本。初始化示例与评测命令见研究报告，运行前需恢复示例 JSON 引用的源图。
